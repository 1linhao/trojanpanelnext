# 项目来源说明

TrojanPanel Next 基于 TrojanPanel 系列开源项目发展而来，是独立维护的整合版本，
不是 TrojanPanel 原组织的官方发行版。

原项目：

- https://github.com/trojanpanel/trojan-panel
- https://github.com/trojanpanel/trojan-panel-ui
- https://github.com/trojanpanel/trojan-panel-core
- https://github.com/trojanpanel/trojan-panel-install-script
- https://github.com/trojanpanel/trojanpanel.github.io

本仓库以 TrojanPanel Next 重构完成时的代码作为全新历史起点，不复制原项目的 Git
提交历史。原项目的完整历史仍保留在以上仓库中。

## English

TrojanPanel Next is an independently maintained, consolidated project derived
from the TrojanPanel open-source projects. It is not an official release of the
original TrojanPanel organization.

The upstream projects are listed above. This repository starts with the
restructured TrojanPanel Next codebase and does not reproduce their Git commit
history; the complete histories remain available in the original repositories.
