# Project origin and migration notice

TrojanPanel Next is a community-maintained continuation and monorepo
reorganization derived from the upstream TrojanPanel projects. It is not an
official release of the upstream organization.

Upstream source projects:

- https://github.com/trojanpanel/trojan-panel
- https://github.com/trojanpanel/trojan-panel-ui
- https://github.com/trojanpanel/trojan-panel-core
- https://github.com/trojanpanel/trojan-panel-install-script
- https://github.com/trojanpanel/trojanpanel.github.io

The exact maintained-fork commits and source tree identifiers used to create
the new root history are recorded in `migration/source-baseline.json`. The
pre-migration commit graphs remain in their original repositories and are not
reproduced in this repository.
