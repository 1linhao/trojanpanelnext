# 架构与领域模型

[文档首页](../README.md) · [开发指南](../development.md)

## 系统组件

| 组件 | 职责 |
| --- | --- |
| Web UI | 账户、节点服务器、代理节点、订阅、流量和内核任务的交互界面 |
| Web API | 业务数据、权限、订阅生成、Node 管理与 mTLS 身份维护 |
| MariaDB / Redis | 持久化业务数据、会话与运行协作数据 |
| Node Agent | 管理代理配置、账户、流量和 Xray / Hysteria2 / NaiveProxy 进程 |
| 宿主机维护服务 | 执行节点服务器卸载，并确认 Web 侧清理结果 |
| Caddy | 公网 HTTPS；Node 可配置外部证书替代此职责 |

Web 与 Node 可部署在独立主机。Node 控制通道为 mTLS gRPC；宿主机维护通道为 mTLS HTTPS。Agent 不挂载 Docker socket，宿主机维护服务在 systemd 下运行。

## 核心概念

- **节点服务器**：安装一个 Node Agent 的主机登记，拥有独立服务器 ID 和 mTLS 管理连接。
- **代理节点**：节点服务器上的一个代理实例；一台服务器可承载多个代理节点。
- **账户**：面板身份和代理访问身份，其额度、有效期和权限由 Web 管理。
- **订阅**：按账户与目标客户端生成的代理配置，支持 Xray、sing-box 和 Clash 系列模板；sing-box 用于生成订阅，在节点上不运行 sing-box 进程。
- **代理内核**：面板可升级的 Xray 和 Hysteria2 二进制。NaiveProxy 是受管理的代理运行时。

## 内核管理

- **版本通道**：根据上游 GitHub Release 的 `prerelease` 标记区分正式版和预发布版。
- **内核修订**：已校验二进制、SHA-256 与安装元数据。
- **当前修订**：持久化目录中 `current` 原子符号链接指向的修订。
- **升级任务**：由管理员创建的审计对象，可包含多个节点服务器与内核目标。
- **任务项**：任务在“服务器 × 内核”上的独立结果；不同服务器之间不执行原子事务。
- **回退**：将 `current` 切换到本地保存的修订，并重启该内核的代理实例。

删除单个代理节点只清理该实例。删除节点服务器先通过宿主机维护服务卸载目标主机服务，成功后清理 Web 登记与关联代理配置；数据保留范围见[卸载说明](../deployment.md#web-removal)。
