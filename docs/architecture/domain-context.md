# 领域上下文

本仓库中的“代理内核”特指节点上承载代理流量的 Xray 与 Hysteria2。NaiveProxy
仍是可用的“节点代理”，但不属于可升级内核；sing-box 只用于生成订阅，不在节点运行。

- **版本通道**：严格采用 GitHub Release 的 `prerelease` 标记。`stable` 表示正式版，
  `prerelease` 表示测试版，`legacy` 表示首次迁移时登记的原镜像二进制。
- **内核修订**：某一代理内核的一个已校验二进制、SHA-256 与安装元数据。
- **当前修订**：持久化目录中 `current` 原子符号链接指向的修订。
- **升级任务**：由 sysadmin 手动创建的面板审计对象，可包含多个节点与多个目标。
- **任务项**：升级任务在“节点 × 内核”上的独立执行结果。不同 VPS 不做原子事务。
- **回退**：把 `current` 恢复到本地历史修订，并重启该内核的全部实例。
- **控制通道**：面板后端到 TP Core 的 gRPC。旧节点为 `legacy`；新节点为 mTLS。

Trojan-Go（类型 ID 2）与 Hysteria v1（类型 ID 3）已经退役。编号和历史表永久保留，
不得复用；新增、编辑及导入必须拒绝这两种类型。
