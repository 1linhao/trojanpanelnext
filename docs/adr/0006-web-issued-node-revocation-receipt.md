# Web 签发可离线核验的 Node 撤销回执

独立 Node 的卸载由操作者先在 Web VPS 撤销身份；Node 失联或销毁时，Web 通过既有 `force-evict` 独立收回权限。Web 在撤销成功后导出绑定签发者、Node 身份和撤销代次上限的签名回执，Node 使用引导包中预置的专用公钥离线验证回执后才进入本机卸载；专用私钥始终留在 Web 的受管数据根，避免向 Node 分发 Web 管理权限，也不复用 TLS CA 私钥签业务数据。

回执证明身份已经进入不可恢复的 revoked/evicted 终态，不授予重新部署权限；同一已撤销身份可重用回执安全续跑卸载，低于本机代次的回执不能放行。归属核验、最后角色判断和显式数据清除仍由安装器独立执行；Web 撤销失败或结果不确定时不签发成功回执，Node 已销毁时无需回传回执或执行本地卸载。
