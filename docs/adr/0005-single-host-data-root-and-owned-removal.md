# 固定宿主业务数据根并按所有权卸载

TrojanPanel Next 的新裸机部署将受管持久业务数据集中到宿主 `/tpdata/trojanpanelnext`，但保留容器内既有路径并逐项挂载，避免把数据库和 Web 凭据暴露给不需要它们的容器。卸载只自动移除身份可证明属于本部署的容器，以及已无任何容器引用的受管发布镜像；普通卸载保留数据，只有最后一个角色退出且显式指定 `--purge-data`，才在校验根目录归属与路径后删除整棵业务数据根。此决定用固定目录和更严格的清理门禁换取可理解、可验证的彻底清除；旧版分散数据不迁移也不自动删除，宿主系统单元和外部证书仍按各自所有权契约处理。
