# 裸机安装提供三种部署模式与不可变发布资产

TrojanPanel Next 把不依赖 VPS 管理系统的裸机安装作为正式产品入口，并以统一配置声明 `web`、`node` 或 `combined` 部署模式。`combined` 在同一宿主上使用两个域名和一个共享入口；默认由 ACME 管理证书，外部入口仍是可选 Adapter。正式发布必须把版本化 bootstrap、模板、安装器和校验材料放在同一 GitHub Release，并以不可变镜像 digest 绑定运行组件，而不是依赖 `latest`。该决策增加了发布清单与三种拓扑的测试成本，换取可复现安装、清晰的端口所有权和不依赖源码仓库的交付。
