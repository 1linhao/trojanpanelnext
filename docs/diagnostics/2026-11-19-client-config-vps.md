## 待提交缺陷

### 窄屏裁切历史版本选择框

在「系统配置 → 节点组分流」至少发布一个版本，把浏览器视口设为 390×844 或 320×700，然后查看「版本历史 → 版本」。实测下拉框仍宽 440px，从 x=31 延伸到 x=471，超出视口的文字和下拉箭头被裁切，页面无法横向滚动。1440×900 下显示正常。验收截图为 `routing-390.png` 和 `routing-1440.png`，保存在本机验收目录。期望选择框及触发按钮在窄屏内完整可见。

缩窄版本字段的网格最小宽度后，在测试 VPS 已发布历史的页面重新测量。320×700、390×844 和 1440×900 三个视口中的选择框均完整位于页面内。

### V2Ray 和 Shadowrocket 订阅二维码编码内部地址

测试面板导出的两个二维码原先都使用 `https://127.0.0.1:8081/`。Nginx 把请求的 Host 替换为 API 回环地址，二维码沿用了该地址。API 现从本机反向代理交接的有效来源头恢复客户端访问地址。实机重新解码后，两种二维码均与复制链接逐字节一致。使用两类客户端的 User-Agent 请求新地址，均得到 HTTP 200 和三条有效节点链接。公网请求附带伪造转发域名时，二维码仍使用测试面板域名。
