## 续跑

原教程的双机流程在 Web 步骤阻塞，同机拓扑也依赖这一前置。记录问题后，实机续跑保留已发布镜像、模板和脚本版本，仅对已核对的本地入口副本补齐下载项。

- Web 通过公开 HTTPS 提供面板，初始登录后修改密码并重新登录成功。
- 双机按候选 README 在面板创建远程 Node、下载部署包、SFTP 上传并执行方式 A。Node Caddy 取得公开证书，远程 Node 在服务器管理中显示「正常」。
- 同机 HTTP-01 签发块为本机 Node 域名取得公开证书，命令退出后 Web Caddy 自动恢复，面板 HTTPS 返回 200。
- 本机部署包按候选 README 的方式 B 原样安装。数据库和 Redis 使用回环地址，本机 Node 使用独立的 PKI 信任目录。
- 在同一面板确认远程 Node 和本机 Node 同时显示「正常」，均上报 CORE v1.0.2-rc.13，运行状态均显示 mTLS。服务器端部署包和 YAML 的权限均为 `0600`。
