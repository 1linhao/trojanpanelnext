## 正确性

安装器只接受 `install`、`remove` 和 `validate` 三个操作，只接受 `web` 与 `node` 两种用途。
CLI 用途与配置中的 `trojanpanelnext.purpose` 必须一致，配置版本固定为 `schema_version: 1`。
端口、布尔开关、必填连接参数及 TLS 模式在执行部署前完成校验。

审查中移除了旧字段别名，使示例配置成为唯一契约；同时将 `--force` 限定为安装参数，
将 `--purge-data` 限定为卸载参数，避免接受无效但看似成功的命令。

## 安全性

`yq` 使用固定版本与架构对应的 SHA-256 校验值下载。Web 首次生成的 MariaDB 和 Redis
密码写回配置文件后将权限设为 `600`，密码不打印到终端。Web 主控自动生成 mTLS 客户端
身份，Node 只接收公开 CA 证书，安装器不再接受 legacy gRPC 模式。配置值按 YAML 数据读取，
不通过 `source`、`eval` 或 `envsubst` 执行或展开，避免密码内容因主机环境而变化。

## 可维护性

仓库只保留一个安装入口和两份用途模板。已删除旧版本脚本、独立脚本、源码构建模式、
旧 Compose 模板、旧配置示例以及迁移快照工具。CI 使用脚本持续检查所有 README 默认中文、
提供英文入口且不包含嵌套列表。
