## 正确性

引导包把身份 ID、代次和 `node_server_id` 同配置绑定，并用摘要固定唯一三文件清单。安装器只在
Node `install|validate` 接受 `--bundle`，先验证 Release，再在 tmpfs 解密和二次验证配置。安装成功
依次要求 Node 专用 MariaDB 身份、两个 Redis ACL 身份、Node API 和 Web→Node mTLS/gRPC 全部健康。
就绪标记与当前身份代次绑定，旧代次标记不能复用。

## 安全性

口令默认从 TTY 读取，自动化只接受 `TP_NODE_BUNDLE_PASSWORD`，不接受命令行口令。输入凭据与
配置要求 `0600`，输出使用不覆盖创建；归档拒绝额外、重复、穿越和超限条目，JSON 拒绝未知字段
与尾随数据。公开 CA 只接受 CA 证书 PEM，含私钥或非 CA 证书时失败。包不携带 Web CA 私钥或
Web 客户端证书/私钥；解密目录固定在 `/dev/shm` 私有目录并由退出 trap 清理。轮换或撤销后，
Node 通过新连接复检发现三组身份失效并退出。

## 可维护性

加解密逻辑收敛到独立 Go helper；Release 生成器、资产契约和无 jq 验证器共享固定 13 项资产集合。
数据层探测支持 `mariadb|redis|all` 独立诊断，输出保持无秘密。中英文 README 和文档站均记录了
生成、传输、安装、Web 验证和换代流程。
