## 2026-11-19 00:09

### 范围

管理员在节点管理页设置全局同步开关和所选服务器。所有登录账号都能在 Web 节点列表看到选定服务器的统计卡片，包括没有可用节点的账号。

### 数据与接口

- MySQL 保存全局开关，升级和新装均默认关闭。所选服务器通过外键关联服务器记录，服务器删除时自动清理选择。关闭后保留选择，方便重新开启。设置和选择在同一事务中保存。
- `GET /api/node/serverTrafficDisplay` 和 `POST /api/node/serverTrafficDisplay` 供系统管理员和管理员读取、更新设置。读取返回开关、已选服务器 ID 和可选服务器的 ID 及名称。更新接收 `enabled` 和 `serverIds`。
- `GET /api/node/serverTrafficSummaries` 在登录后提供已选服务器的名称、周期、使用量和额度。查询复用现有服务器流量聚合，过滤正在移除的服务器。开关关闭、未选服务器或服务器全部移除时，返回空列表。

### 展示与统计口径

- 卡片显示已用流量和总额度。日、月、年沿用服务器的统计周期。不限额的服务器显示累计流量和「无限制」。分开限额时显示上下行各自的已用流量和额度。两方向均设限时，合计额度等于两者之和；任一方向无限制时，合计显示「无限制」。
- 统计卡片随 Web 节点列表加载，并在管理员保存后刷新。节点搜索、服务器筛选和分页仍操作实际节点。卡片的展示位置固定在节点列表上方，卡片仅含汇总信息。
- 使用节点列表和流量接口的独立请求。节点列表、节点管理操作、连接信息和订阅继续读取实际节点。
